# G-STAR 2026 관람 가이드

게임 체험·관람 안내, 전시장별 부스 지도, 편의시설, 센텀프리미어호텔과 주변 식당 정보를 담은 정적 웹페이지입니다.

## 실행과 배포

별도 빌드가 필요하지 않습니다. `index.html`과 CSS·JavaScript·`assets/`를 같은 구조로 유지합니다.

GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.

## 자료

게임 정보는 `data.js`, 전시장 지도는 `maps.js`, 편의시설은 `facilities.js`, 식당은 `restaurants-data.js`에 있습니다. 숙소와 본문은 `index.html`에 있습니다.

식당 건수 등 자료별 기준일·확인 범위 및 외부 이미지·지도 출처는 페이지에 표시되어 있습니다.
